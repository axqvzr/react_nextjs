# REACT JS

`REACT is JS library`

`REACT reacts to state changes by re-redering the UI.`

## Setup

- Install VS code
- Install Nodejs
  - node -v
  - npm -v
- Useful VS Code extension
  - ESlint
  - prettier
  - One monokai theme
  - Material icon theme

## Settings

- Autosave : after delay
- Set default formatter to prettier
- Turn on format on save
- Eslint run : onSave

## Crating react app

### Using create-react-app

- `npx create-react-app myApp`
- To include version `npx create-react-app@5 myApp`
- complete starter kit for react application
- Everything is already configured: ESlint, Prettier, Jest etc
- uses slow & outdated technologies(i.e webpack)
- > NOT RECOMMEDED nowadays!!

### Using vite

- `npm create vite@latest`
- Uses modern tools and need to setup manually
- Fast and use in real world apps
- > RECOMMEDED

> REACT team now advises to use react framework for new projects like nextjs, remix etc
